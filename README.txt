ccminer-next 0.0.0 prerelease
------------------

Based on the original ccminer by Christian Buchner, Christian H. and later
contributors (tpruvot, djm34, tsiv, sp, klausT, and others).

This is a CUDA-accelerated miner supporting multiple algorithms. Run:

    ccminer-next --help

for the full list of supported algorithms and options.
